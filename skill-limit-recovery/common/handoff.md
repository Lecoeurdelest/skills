# Handoff Requirements

Create or update `HANDOFF.md`.

Use this minimum structure:

```markdown
# AI Task Handoff

## Objective
Exact task objective.

## Current Status
- State:
- Task ID:
- Branch:
- Current phase:
- Last completed phase:

## Completed Work
Verified completed work only.

## Changes Made
| File or component | Change | Reason | Verification |
|---|---|---|---|

## Commands Executed
| Command | Result | Evidence |
|---|---|---|

## Tests
- Passed:
- Failed:
- Not executed:
- Previously reported but not revalidated:

## Approved Decisions
| Decision | Rationale | Evidence |
|---|---|---|

## Assumptions
| Assumption | Confidence | Required validation |
|---|---|---|

## Known Risks
| Risk | Impact | Mitigation |
|---|---|---|

## Exact Next Action
One concrete first action for the next session.

## Do Not Do
Rejected approaches, forbidden changes, or conclusions not to repeat.

## Acceptance Criteria
Conditions required for completion.
```

The handoff must point to durable evidence rather than relying on conversation memory.
